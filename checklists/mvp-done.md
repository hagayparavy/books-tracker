# MVP Definition of Done

## Product

- [ ] User can sign in with Google.
- [ ] User can add, edit, delete books.
- [ ] User can update reading progress.
- [ ] User can move books across statuses/shelves.
- [ ] User can view reading session history.

## Platforms

- [ ] Web app usable on desktop/tablet/mobile browser.
- [ ] Android app supports core CRUD and progress flows.

## Quality

- [ ] Backend unit and integration tests are green.
- [ ] Web tests cover critical user flows.
- [ ] Android basic tests for navigation/forms are green.
- [ ] OpenAPI contract is published and consumable.

## Operations

- [ ] CI passes independently in each repository.
- [ ] Staging deployment works and health checks pass.
- [ ] Release checklist executed for at least one tagged version.

## Documentation

- [ ] Setup instructions are accurate from clean machine.
- [ ] Known limitations and next steps are documented.
