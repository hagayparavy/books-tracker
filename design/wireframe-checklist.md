# Wireframe Checklist

Use this checklist before moving to visual design.

## Global

- [ ] Navigation pattern chosen for mobile and desktop.
- [ ] States defined: loading, empty, error, success.
- [ ] Auth entry and logged-in shell wireframed.

## Screens

- [ ] Library/List screen (filters by status/shelf)
- [ ] Book detail screen
- [ ] Add/Edit book form
- [ ] Progress update modal/screen
- [ ] Reading sessions history screen
- [ ] Settings/profile screen
- [ ] Sign-in screen

## Per-Screen Validation

- [ ] Primary CTA is obvious and reachable.
- [ ] Secondary actions are non-destructive by default.
- [ ] Destructive actions include confirmation pattern.
- [ ] Critical metadata appears above fold on mobile.

## Cross-Device Variants

- [ ] Mobile layout version
- [ ] Tablet layout version
- [ ] Desktop layout version

## Review Pass

- [ ] End-to-end flow: sign-in -> add book -> log progress -> view history
- [ ] Interaction notes attached to each wireframe
- [ ] Open questions listed before implementation
