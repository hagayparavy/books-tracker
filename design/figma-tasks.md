# Figma Tasks

## Lesson Goal

Produce implementation-ready design artifacts with consistent component structure.

## Task 1: File Setup

1. Create pages: `Foundations`, `Components`, `Flows`, `Handoff`.
2. Add frame presets for phone, tablet, desktop.
3. Create basic color and typography styles.

## Task 2: Design Tokens

1. Define spacing scale (4/8-based).
2. Define type scale for body, heading, caption.
3. Create semantic color tokens: primary, neutral, success, warning, error.

## Task 3: Component Library

1. Build button variants (primary, secondary, destructive, disabled).
2. Build form controls (text input, select, textarea, validation states).
3. Build book card component with status/progress variants.
4. Build top navigation and mobile bottom navigation.

## Task 4: Core Flows

1. Sign-in flow.
2. Add-book flow.
3. Update-progress flow.
4. Move-book-between-status flow.

For each flow:

- Include starting state, in-progress state, and success state.
- Include at least one error state.

## Task 5: Responsive Adaptation

1. Duplicate core screens across phone/tablet/desktop.
2. Adjust information density per breakpoint.
3. Keep interaction hierarchy consistent.

## Task 6: Handoff Readiness

- Add annotations for spacing and behavior.
- Name layers/components consistently.
- Ensure reusable components are not detached.
- Export a short handoff note for each screen.
