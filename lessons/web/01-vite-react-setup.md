# Web Lesson 01: Vite + React Setup

## Outcomes

- Create web application shell with routing.
- Establish API layer boundary and error handling baseline.

## Tasks

1. Initialize project with Vite + TypeScript.
2. Configure router and route-level layout shell.
3. Create API client module boundary (no direct fetch calls from components).
4. Add global error boundary and not-found route.
5. Define environment configuration strategy for API base URL.

## Acceptance Criteria

- App starts with one command.
- Route navigation works for primary screens.
- API layer can be mocked for tests.
