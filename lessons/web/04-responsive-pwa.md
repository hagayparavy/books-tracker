# Web Lesson 04: Responsive Design and Optional PWA

## Outcomes

- Ensure browser usability across desktop, tablet, and mobile.
- Optionally package as installable PWA.

## Tasks

1. Implement responsive layout according to design breakpoints.
2. Validate touch and keyboard accessibility.
3. Optimize list and detail layouts for narrow screens.
4. Optionally add PWA manifest and service worker.
5. Test fallback behavior for offline/slow network.

## Acceptance Criteria

- Core flows are usable at mobile and desktop breakpoints.
- Navigation patterns are consistent with design docs.
- PWA install works if enabled, without breaking non-PWA usage.
