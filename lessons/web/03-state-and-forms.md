# Web Lesson 03: State Management and Forms

## Outcomes

- Manage server state predictably.
- Build robust forms for book and progress workflows.

## Tasks

1. Add server-state library (for example React Query).
2. Define query keys and cache invalidation strategy.
3. Implement form architecture with schema validation.
4. Create optimistic update policy for safe operations only.
5. Implement error handling for validation and network failures.

## Required Flows

- Add book
- Edit book metadata
- Update reading progress
- Move book status/shelf

## Acceptance Criteria

- Forms provide inline validation and success feedback.
- Cache consistency is maintained after mutations.
- Error states are user-friendly and recoverable.
